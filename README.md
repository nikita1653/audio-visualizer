# audio-visualizer
Real-time audio visualizer using JavaScript and Web Audio API

A browser-based audio visualizer built using JavaScript and the Web Audio API.
The application analyzes audio frequencies in real time and renders dynamic visual effects.

## Features
- Real-time audio frequency analysis
- Dynamic visual animations
- Uses Web Audio API and HTML Canvas

## Tech Stack
- HTML
- CSS
- JavaScript (Web Audio API)

This project demonstrates real-time data processing and interactive visual rendering in the browser.
